# 다양화 로드맵

## 설계 원칙

- 주인공은 먼치킨 성장과 규칙을 깨는 조합(증강체·공명)이다. 보상은 빠르게 주고, 반복 노가다·벽 같은 보스·긴 튜토리얼은 넣지 않는다.
- 새 구조는 비슷한 인기작에서 검증된 것을 가져오되, 증강체·공명 축을 키우는 쪽으로 바꾼다.
- 바꾼 뒤에는 `node scripts/levels.ts 1000`으로 라운드별·편성별 승률과 전투 시간을 확인한다.

## v0.2.0에서 데이터로 본 문제

라운드별 수치는 봇 300판(공명 노림, 해금 없음), 클리어율은 1,000판, 그리고 실제 화면 플레이 1판 기준.

| 구간 | 공명 봇 첫 시도 승률 | 승리 때 남은 체력 | 전투 시간 | 문제 |
|---|---|---|---|---|
| 1~4R | 100% | 90% | 6~7초 | 긴장 없음 (초반이라 의도된 쉬움) |
| 5R 정예 트롤 | 75% | 45% | 24초, 24%가 30초 넘김 | 체력 덩어리를 오래 두드리는 싸움 |
| 6~9R | 99~100% | 74~86% | 9~12초 | 배치 말고는 할 결정이 없음 |
| 10R 정예 전갈 | 67% (무작위 봇 53%) | 49% | 22초 | 최종 보스보다 높은 벽 |
| 11~14R | 91~96% | 60% | 9~11초 | |
| 15R 보스 | 75% | 39% | 23초 | |

- 일반 편성은 구역 풀에서 무작위로 뽑은 적 묶음이라, 적을 보고 배치를 바꿀 이유가 없었다.
- 전부 해금하면 클리어 96%, 클리어 때 생명 3.6개가 남는다. 클리어 뒤 할 것이 없다.
- 후반에 매 라운드 골드가 13~27 남는다. 실제 플레이에서는 1라운드 황금 손으로 2라운드에 ★2 넷, 6라운드에 ★3 둘이 나왔다. 대기석이 차면 산 유닛이 자동으로 팔린다.

괄호는 동방을 넣기 전(fc86496)에 같은 스크립트·같은 시드로 잰 값. 동방 유닛을 증강체 뒤로 옮긴 뒤 ★ 평균은 넣기 전과 같다(15R 무작위 2.13, 공명 2.24). 무작위 봇에 남은 차이는 같은 시드 600판으로 요소를 하나씩 빼 보면 동방의 부름(무작위로 고르면 동방 유닛을 모으지 않아 약한 프리즘)과 동방 유물(유물 모루 후보가 묽어짐)에서 각각 2~3%p다. 조합표 45종·숨은 아이템을 넣기 전(74%·81%·97%)과 넣은 뒤는 거의 같았다. 숨은 아이템은 무작위 봇이 판당 1개꼴(유물 0.8·찬란한 0.2), 공명 봇이 0.4개(보물 창고를 덜 고름). 보물 창고를 완벽히 턴 비율은 64~79%.

## 다음 마일스톤: LÖVE 이식

웹(Vite + TypeScript, 전투는 Canvas 2D, 화면은 HTML/CSS)에서 LÖVE 11.5(Lua, LuaJIT)로 옮긴다. 소리(love.audio)·셰이더·데스크톱 실행 파일·Android APK를 한 코드로 낸다. 웹판은 이식이 끝날 때까지 Pages에 그대로 두고 새 기능을 넣지 않는다 — 같은 시드의 결과를 맞춰 보는 기준 구현이다. Capacitor로 웹판을 감싸는 APK 계획은 이 이식으로 대신한다.

| 단계 | 내용 | 끝났다는 기준 |
|---|---|---|
| 0. 뼈대 | 저장소 안 `love/`에 `main.lua`·`conf.lua`. 갈무리 글꼴은 지금 woff2에서 TTF로 변환, 스프라이트는 `public/sprites`를 함께 쓴다 | 창에 한글·스프라이트가 뜬다 |
| 1. 규칙 | `rng`·`battle`·`data/*`·`run`·`meta`·`heroes`를 Lua로. 헤드리스 검사(`scripts/sim.ts`)도 luajit로 옮긴다 | 같은 시드에서 TS와 Lua의 전투 결과(유닛별 남은 체력·준 피해)가 같고, 봇 300판 클리어율이 TS와 같은 범위 |
| 2. 전투 화면 | `arena.ts` → love.graphics: 바닥 타일, 2프레임 애니메이션, 파티클, 흔들림, 히트스톱, 슬로모션, 줌, 공명 컷인 | 웹판과 같은 연출 |
| 3. 준비 화면 | 상점·보드·대기석·끌어 놓기·설명창·시너지·증강체·보상·갈림길·사건. 9분할 패널·버튼·한글 줄바꿈을 직접 그린다 | 한 판 완주 |
| 4. 나머지 화면 | 타이틀·도감·영구 성장·위험도·일일 도전·샌드박스·나만의 영웅(한글 이름 입력) | 웹판 기능 전부 |
| 5. 저장 | love.filesystem에 JSON. 웹판 저장 옮기기는 선택 | 이어하기·영구 성장 |
| 6. 소리 | 연출 이벤트(Fx)에 효과음, 화면·구역별 배경음, 음량 설정. 무료 CC0 팩부터 | |
| 7. 배포 | Windows·macOS 실행 파일, Android APK(love-android, 가로 고정, 길게 눌러 설명창) | 갤럭시 실기기에서 한 판 |

옮길 때 지킬 것:
- 결과에 영향을 주는 반복은 배열로 한다. Lua `pairs`는 순서가 정해져 있지 않다.
- 난수(mulberry32)의 32비트 곱셈(`Math.imul`)은 16비트씩 나눠 곱해 같은 값을 낸다(LuaJIT `bit`).
- 배열은 1부터 센다. 칸 번호·시드처럼 저장되는 값은 0부터 그대로 둔다.
