# 다양화 로드맵

## 설계 원칙

- 주인공은 먼치킨 성장과 규칙을 깨는 조합(증강체·공명)이다. 보상은 빠르게 주고, 반복 노가다·벽 같은 보스·긴 튜토리얼은 넣지 않는다.
- 새 구조는 비슷한 인기작에서 검증된 것을 가져오되, 증강체·공명 축을 키우는 쪽으로 바꾼다.
- 바꾼 뒤에는 `node scripts/levels.ts 1000`으로 라운드별·편성별 승률과 전투 시간을 확인한다.

## v0.2.0에서 데이터로 본 문제

라운드별 수치는 봇 300판(공명 노림, 해금 없음), 클리어율은 1,000판, 그리고 실제 화면 플레이 1판 기준.

| 구간 | 공명 봇 첫 시도 승률 | 승리 때 남은 체력 | 전투 시간 | 문제 |
|---|---|---|---|---|
| 1~4R | 100% | 90% | 6~7초 | 긴장 없음 (초반이라 의도된 쉬움) |
| 5R 정예 트롤 | 75% | 45% | 24초, 24%가 30초 넘김 | 체력 덩어리를 오래 두드리는 싸움 |
| 6~9R | 99~100% | 74~86% | 9~12초 | 배치 말고는 할 결정이 없음 |
| 10R 정예 전갈 | 67% (무작위 봇 53%) | 49% | 22초 | 최종 보스보다 높은 벽 |
| 11~14R | 91~96% | 60% | 9~11초 | |
| 15R 보스 | 75% | 39% | 23초 | |

- 일반 편성은 구역 풀에서 무작위로 뽑은 적 묶음이라, 적을 보고 배치를 바꿀 이유가 없었다.
- 전부 해금하면 클리어 96%, 클리어 때 생명 3.6개가 남는다. 클리어 뒤 할 것이 없다.
- 후반에 매 라운드 골드가 13~27 남는다. 실제 플레이에서는 1라운드 황금 손으로 2라운드에 ★2 넷, 6라운드에 ★3 둘이 나왔다. 대기석이 차면 산 유닛이 자동으로 팔린다.
